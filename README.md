# Bếp Nhà Thanh — Website đặt món

Next.js (App Router) + React + Tailwind CSS v4. Thiết kế theo design system "Bếp Nhà Thanh".

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

Trang: `/` · `/thuc-don` · `/thuc-don/[id]` · `/thanh-toan` · `/dat-hang-thanh-cong` · `/ve-bep` · `/lien-he`

Món nằm ở `src/lib/data.ts`; ảnh ở `public/images`. Giỏ hàng lưu ở localStorage (chưa có backend).
